Nashmia Ch — Information Security Portfolio

This is a responsive personal portfolio for Nashmia Ch, a BS Information Security
student at NUST. It presents information security coursework, certifications,
technical skills, practical projects, current learning, and contact information.
The visual design uses an off-white paper background, cobalt, tomato and sunflower
accents, bold outlines, hard shadows, Bricolage Grotesque headings and DM Sans body
text.

The site is designed to work consistently on laptops, tablets and smaller screens.
Project cards use consistent artwork sizing, certification details remain readable
inside their frames, and the About section uses the available page width.

The site runs with vanilla JavaScript and Bootstrap, with no jQuery. Animations
respect prefers-reduced-motion, and the main content remains available when
JavaScript is disabled.

WHAT'S INSIDE
  index.html            Main portfolio page
  projects.html         Project listing page from the original site structure
  commissions.html      Commission page from the original site structure
  assets/               Project diagrams and profile image
  css/vendor/           Bootstrap CSS (self-hosted)
  css/style.css         Responsive design, layout, typography and components
  js/vendor/            Bootstrap JavaScript bundle
  js/main.js            Vanilla JavaScript interactions

NOTES
  - Edit colours, fonts and outline weight through the custom properties at the
    top of css/style.css.
  - Project diagrams are stored in assets/ and referenced from index.html.
  - Repository links in the project cards point to Nashmia's GitHub projects.
  - The contact forms and interactive controls are front-end demonstrations and
    require a backend or form service to become live.
