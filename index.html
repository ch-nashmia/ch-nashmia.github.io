Web data and automation

WEB_SCRAPING_MongoDB

View Repository

Built a Scrapy web scraper that collects book titles, prices, ratings, and availability from Books to Scrape. The project handles pagination, processes items through pipelines, stores structured records in MongoDB, and prevents duplicate entries. This project demonstrates Python automation, data extraction, database integration, and reliable data handling. Tools: Python, Scrapy, MongoDB.

Data mining

GIT_DATA_MINING

View Repository

Developed a Python data-mining project that connects to the GitHub REST API to collect repository and user information. The project processes API responses, organizes useful fields, and stores the resulting data for analysis. It demonstrates API integration, structured data processing, automation, and responsible use of publicly available developer data. Tools: Python, GitHub REST API.

Web development

Django_Portfolio

View Repository

Created a responsive portfolio website with Django to present projects, technologies, and project images in a structured interface. The application includes an integrated Django admin panel for managing portfolio content and uses reusable page components for consistent presentation. This project demonstrates web development, backend organization, database-backed content management, and responsive design. Tools: Python, Django, HTML, CSS.

Network security

Python Port Scanner

View GitHub Profile

Built a Python-based network utility that checks selected ports and identifies which services are reachable on a target system. The project uses socket connections, configurable port ranges, and clear terminal output to report scan results. It supports my study of TCP networking, service discovery, and introductory vulnerability-assessment workflows. Tools: Python, sockets.
